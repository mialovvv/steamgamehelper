# Steam Game Helper

Утилита на Rust для автоматического выбора аккаунта Steam при запуске игр и независимого управления автономным режимом.

Разработана в нативном стиле Windows 11 (Fluent Design) с упором на быстродействие, чистый интерфейс без лишнего хрома и отсутствие внешних зависимостей.

---

## Возможности

- **Авто-выбор аккаунта:** сканирует библиотеки Steam и файлы манифестов (`appmanifest_*.acf`). При нажатии «Играть» программа проверяет текущую сессию Steam: если активен другой профиль, клиент корректно перезапускается под нужным аккаунтом без запроса пароля и сразу стартует игра.
- **Индивидуальный автономный режим:** возможность переключать оффлайн-режим (`WantsOfflineMode`) для каждого аккаунта отдельно в `loginusers.vdf`. Позволяет держать один аккаунт в оффлайне для одиночных игр, не мешая сетевым сессиям на других устройствах.
- **Локальный кэш обложек:** автоматически находит и отображает постеры игр из локального кэша Steam (`appcache/librarycache`) без обращения к интернету.
- **Интерфейс Windows 11:** выполнен на `egui / eframe` с боковой панелью навигации, поиском по названию/ID и индикатором статуса клиента Steam.
- **Поддержка командной строки (CLI):** возможность создавать ярлыки для мгновенного запуска игр с авто-входом:
  ```powershell
  steamgamehelper.exe 1245620
  ```

## Скачивание и запуск

Программа поставляется в виде одного переносимого `.exe` файла и не требует установки сторонних библиотек:

1. Скачайте `SteamGameHelper.zip` из раздела [Releases]([https://github.com/](https://github.com/mialovvv/steamgamehelper/releases)).
2. Запустите файл на Windows 10 или 11.

---

## Сборка из исходников

Требуется установленный Rust (1.80+):

```bash
git clone https://github.com/your-username/steamgamehelper.git
cd steamgamehelper
cargo build --release
```

Готовый бинарник будет находиться по пути:
```
target/release/steamgamehelper.exe
```

## Стек технологий

- **Язык:** Rust (Edition 2024)
- **GUI:** `eframe` / `egui 0.37`
- **Интеграция с реестром:** `winreg`
- **Графика:** `image`
- **Формат данных:** собственный потоковый парсер Valve KeyValues (VDF / ACF)
